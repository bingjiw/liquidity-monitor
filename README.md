# 美元流动性综合指标

一个 Python 脚本,从 FRED、纽约联储、美国财政部的免费公开数据计算 0–100 的每日流动性指数(50 = 三年中性,越低越紧),外加硬预警和未来 30 天结算日历。不调用任何大模型。设计说明见项目文档《流动性跟踪指标:视频观点分析与设计方案》。

## 安装与运行

```bash
pip3 install pandas requests
python3 liquidity_monitor.py
```

第一次运行会下载 2018 年以来的历史数据(约 1 分钟),之后每次几秒钟。输出在 `output/`:

- `report_latest.md`:当日报告(综合指数、五大支柱、关键读数、各序列贡献、预警、结算日历)
- `liquidity_history.csv`:每日指数历史,可以导入 Excel 画图
- `raw_data.csv`:对齐后的原始数据
- `cache/`:下载缓存,某个数据源临时失败时会自动用缓存

## 可视化仪表盘

每次运行都会生成 `docs/index.html`:综合指数历史走势(1 年 / 3 年 / 5 年 / 全部)、五大支柱、任意单项指标、任意两天对比、今日各序列贡献、每日运行记录。开启 GitHub Pages(Settings → Pages → Branch: main, 文件夹 /docs)后可用网址直接打开;否则下载该文件用浏览器打开。

`output/daily_log.csv` 每次运行追加一行当时的计算结果,不会被改写,用于回看“当时看到的是什么”。

## 历史校准与操作信号

`backtest/` 用 2019 年以来的历史数据检验仪表盘能不能指导美股仓位(SPY、QQQ 复权价由 `backtest/fetch_market.py` 抓取)。回测按每个序列的实际公布时间滞后重算指数,信号次日执行,扣换仓成本,2019-03~2022-12 定规则、2023 年以后做样本外检验。完整结果在 [output/backtest_summary.md](output/backtest_summary.md)。

结论:

- **综合指数本身不适合直接用来加减仓**。按“低于某个分数连续多少天就减仓”或“相对自己一年均值走弱就减仓”交易,扣掉仓位差异后都没有跑赢同等仓位的买入持有。它抓到了 2022 年的紧缩,但 2023 年后一直偏紧,而美股是大牛市。它适合当环境和风险预警看。
- **推荐规则:净流动性(联储总资产 − TGA − 逆回购)13 周变化**。连续 20 个交易日为负 → 股票减到半仓;连续 20 个交易日为正 → 回到满仓。样本内和样本外都跑赢同等仓位对照,换参数(窗口 40~130 天、确认 5~40 天)大多仍为正。
- 它躲不开 2020 年疫情、2025 年 4 月关税这类突发冲击,只管宏观流动性的大周期。

每天运行时会顺带抓股价、更新信号,仪表盘顶部的“历史校准信号”显示当前建议仓位和离下一次切换还差几天,图上红色底色是历史上的半仓时段。

## 每天自动运行

本仓库用 GitHub Actions(`.github/workflows/daily.yml`)在每个工作日 UTC 23:30(北京时间次日 7:30)自动运行,结果提交到 `output/`。最新报告见 [output/report_latest.md](output/report_latest.md)。在 Actions 页面点 Run workflow 可随时手动运行。

### 也可以在本机运行(Mac)

`crontab -e` 加一行(北京时间每个工作日早上 7:30,对应美东前一天傍晚,数据已更新):

```
30 7 * * 2-6 cd /path/to/liquidity && /usr/bin/python3 liquidity_monitor.py >> output/run.log 2>&1
```

## 调整

权重、序列、预警阈值都在脚本开头的配置区:`PILLAR_WEIGHTS`、`SCORED`、`ALERTS`。某个 FRED 序列下载失败时脚本会跳过它,并按剩余权重重新归一。

仅用于研究,不构成投资建议。

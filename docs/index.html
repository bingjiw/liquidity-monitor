    各规则成绩对比

    “同仓位对照”= 一直持有和该规则平均仓位相同比例的股票。“择时增益”= 年化 − 同仓位对照,只有它为正才说明这套数据真的帮上了忙,而不只是少买了股票。“判断正确率”= 每次调仓之后到下一次调仓之间:减仓段股票跑输现金、加仓段股票跑赢现金,算判断正确。

    所选规则:之后三个月的概率

    按规则处于满仓或减仓状态的每一天,统计之后 63 个交易日股票的涨跌。减仓时的上涨概率和平均涨幅如果明显低于满仓时,说明这套数据能区分好坏时期;反过来就说明它常在不该减仓的时候减仓。
